> 这份清单是给**人**看的。剪映 7+ **没有可自动化的导出接口**
> （`pyJianYingDraft` 的 `JianyingController.export_draft` 明确写着"仅支持剪映6及以下版本"）。
>
> 环境：剪映专业版 **11.4.2.14459**，草稿目录
> `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`

### 本轮按你三条反馈改了什么

| 你的反馈 | 改了什么 |
|---|---|
| **切割得太严重** | **15 镜/14 切/均长 1.00s → 9 镜/8 切/均长 1.667s**。仍全部落在 128BPM 拍点上，只是呼吸更长：4+4+4+2+2+4+4+4+4 = 32 拍 = 8 小节 |
| **转场不够高级** | **闪白 0.08s → 信号故障 0.12s**（VIP 故障转场），drop 那一下给到 0.20s。8 个切点里 6 处用转场、**2 处故意硬切**（进"吸气镜"的那一下必须硬切 —— 静止要干净地到来） |
| **低级反馈特效不要用了** | 删掉 **冲击波 / 闪光震动 / 星火炸开**（都是基础档"反馈"特效），换成同一套**高级故障语言**：**像素故障**（7.5s DROP）、**幻彩故障**（9.375s）、**花屏故障**（13.125s 收尾），只打在能量峰值上 |

顺带修了一处**两版手感不一致**：推镜量此前写成绝对终点值，导致竖屏只推 8.5%、横屏推 28%；
现在改成相对倍率（竖屏 5–9%、横屏同比例）。

## 1. ⚠️ 首次打开：3 个 VIP 特效需要联网下载

我实测过本机 `Cache\`（29,369 个文件 / 754.9 MB 文本），逐个查了本轮用到的素材：

| 素材 | id | 本机缓存 | 结论 |
|---|---|---|---|
| **信号故障**（转场） | effect_id `25265947` | **命中** | **零下载风险，一定能显示** |
| **像素故障**（特效） | effect_id `14523597` | 未命中 | 首次打开需**联网下载** |
| **幻彩故障**（特效） | effect_id `1005744` | 未命中 | 首次打开需**联网下载** |
| **花屏故障**（特效） | effect_id `86397374` | 未命中 | 首次打开需**联网下载** |

**剪映的滤镜/特效/字体都是按 id 联网下载的** —— "写进草稿"≠"打开就能用"。
所以：**第一次打开 `GAME_MONT_VT` 时请保持联网**，让剪映把这三个特效拉下来。

- 若某个特效显示 **"加载失败"**：让它联网重下一次即可（不是草稿坏了）。剪映还会把草稿
  **加密回存**，所以别在剪映目录里那份上改；工作区的 `projects/game-001/draft-out/` 才是明文母本。
- 若实在下不动，告诉我，我换成**免费**的故障特效（`色差故障 634773` / `荧幕噪点 634779` /
  `横纹故障 703269`，都是免费档，通常秒下）。

## 2. BGM：现在是本地合成的，建议你换掉

现在这条 BGM 是我**本地合成**的（`projects/game-001/bgm/bgm_128_15s.wav`，
128BPM / 8 小节 / 15.000s；实测底鼓在拍/拍间能量比 **4.57**、drop 在 7.5s 抬升 **1.21×**）。
理由：**剪映曲库无法程序化引用**（`AudioSegment` 只收本地文件），自己合成才能保证拍点与剪切点同格。

但它不是专业制作的曲子。**你充了会员，建议在剪映里换成热门曲**：

- 新曲 BPM 取 **120–140**（调研给出的电竞区间）。
- 现在的剪切点：**1.875 / 3.75 / 5.625 / 6.5625 / 7.5 / 9.375 / 11.25 / 13.125 s**
  （全是 128BPM 的拍点，1 拍 = 0.46875s；重音在 **7.5s 的 drop** 与 13.125s 的收尾）。
- 最省事：音乐拖到 0 秒对齐，再用剪映的"踩点"功能微调轨道位置。

## 4. 人工必做的 3 件事

### 4.1 加限幅器（**EDL 表达不了**）

三段原素材的**真峰值都是 +0.8 dBFS（已经削顶）**。EDL 里只能写音量倍数，写不出"限幅到 −1.0 dBTP"。

1. 选中主轨视频 → 音频面板 → 挂一个**限制器**，输出上限 **−1.0 dBTP**

> **两个实测坑**：
> ① `alimiter` 类插件的 **auto level 默认开启**，会把限幅结果又拉回去 ——
> 同一素材：默认时 **−10.5 LUFS / 真峰值 +0.6 dBFS（削顶）**；关掉后 **−13.4 LUFS / −1.7 dBFS**。
> **"挂了限幅器"≠"限幅生效"，务必量真峰值确认。**
> ② 我这版预览实测 **−15.4 LUFS / 真峰值 −2.7 dBFS**（不削顶，但比抖音常见落点略保守）。
> 想要更响可以把主轨音量整体提 1–2 dB，再压限幅器。

### 4.2 核对顶部遮挡与字框（竖屏专有）

- 规格只建模了抖音**底部 ≈300px** 与**右侧 ≈120px** 的 UI 遮挡带，**顶部遮挡没有建模**。
- 钩子"别眨眼"中心在 **300px**（字框 ≈[233, 367]）—— 请用**抖音预览**确认不被顶部压住。

### 4.3 素材"看得见"确认

剪映 11.x 对**不认识的字段是静默忽略**的（不报错、不显示）。请逐项确认：

| 该看到什么 | 在哪条轨 | 时间点 |
|---|---|---|
| 信号故障转场 | main | 1.875 / 3.75 / 7.50(0.20s) / 9.375 / 11.25 / 13.125s |
| **像素故障** 特效 | `fx` | 7.50s（DROP） |
| **幻彩故障** 特效 | `fx2` | 9.375s |
| **花屏故障** 特效 | `fx` | 13.125s |
| 调色（青橙，全片一致） | main | 全部 9 个片段 |
| 模糊背景填充（上下无黑边） | main | 全部 9 个片段 |
| 推镜关键帧 | main | m01/m02/m03/m06/m07/m08/m09 |
| 吸气镜（0.5× 近乎静止的一拍） | main | 6.5625–7.5s |
| 6 条字幕（各自入场/循环动效） | `cap_top` / `cap_body` | 见下 |
| BGM | `bgm` | 0–15s |
| 9 条音效 | `sfx1` / `sfx2` | 1.875 / 3.75 / 5.625 / 7.5 / 9.375 / 11.25 / 13.125s |

字幕落点：`别眨眼` 0.0s（上）、`2 HP` 1.875s、`听声辨位` 3.75s、`一枪一个` 7.5s、
`已部署` 9.375s（均在下部 1450px）、`这枪换你，敢不敢上？` 13.125s（上部 300px）。
