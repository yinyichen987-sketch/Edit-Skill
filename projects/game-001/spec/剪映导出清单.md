## 1. 只需要打开一次的自动化校准（30 秒）

`DSH_SIZE_LADDER` 里放了 4 个不同字号的同一句话。**你只要在剪映里点开它一次**，
剪映就会把 `draft_cover.jpg` 写到草稿目录；我随后用那张封面把「字号→像素」的换算钉死。

**为什么需要**：本轮已从剪映自渲染的封面实测出 `em_px ≈ 5.55 × size`
（默认字号 8.0 → 实测 ink 高 43px、总宽 456px，两个独立量同时收敛到 em ≈ 44.4px）。
据此把字幕从 size 5.0/6.0 提到 17–24 —— **原值实际只有 ≈28–33px，小了约 3 倍**。
标定阶梯是为了把"一个点"变成"四个点"，确认线性并修正常数。

打开过之后告诉我一声即可。

## 2. 人工必做的 3 件事（剪映没有接口，只能人做）

### 2.1 加限幅器（**这一条 EDL 表达不了**）

实测三段原素材的**真峰值都是正的**（+0.8 dBFS，已经削顶）：

| 片段 | 真峰值 | 响度 |
|---|---|---|
| a | +0.8 dBFS | −12.9 LUFS |
| b | +0.8 dBFS | −14.6 LUFS |
| c | +0.8 dBFS | −15.2 LUFS |

EDL 里只能写**音量倍数**，写不出"限幅到 −1.0 dBTP"。请在剪映里：

1. 选中主轨视频 → 音频面板
2. 挂一个**限制器/压缩器**，输出上限设 **−1.0 dBTP**
3. 三段素材响度差约 2.3 LU，可再用音量关键帧把 b、c 各提约 1–2 dB 对齐

> 不做这一步，抖音/哔哩的响度归一化会把你的片子整体压下去，听感发闷。

### 2.2 核对顶部遮挡与字框（竖屏专有）

- 规格只建模了抖音**底部 ≈300px** 与**右侧 ≈120px** 的 UI 遮挡带，
  **顶部遮挡没有建模**（`format-spec.md §13` 已声明）。
- 钩子字幕中心在 **300px**（字框 ≈[233, 367]）——请在剪映里用**抖音预览**确认
  它不被顶部状态栏/标签压住。
- 若被压住：把 t1 的 `transform_y` 从 `+0.6875` 往下调（改小绝对值），
  重跑 `edl_to_draft.py` 即可，不要手改草稿。

### 2.3 特效与滤镜的"看得见"确认

调研确认剪映 11.x 对**不认识的字段是静默忽略**的（不报错、不显示）。所以请逐项确认：

| 该看到什么 | 在哪条轨 | 时间点 |
|---|---|---|
| 冲击波 | `fx` | 0.30s / 9.95s |
| 闪光震动 | `fx` | 2.35s |
| 闪白 | `fx2` | 9.95s |
| 星火炸开 | `fx` | 12.05s |
| 3 条音效（impact_a / impact_b / win） | `sfx` | 0.30 / 9.95 / 12.05s |
| 字幕描边 + 阴影 | `caption` | 全部 5 条 |
| 字幕入场动效（弹入/向上滑动/渐显） | `caption` | 全部 5 条 |
| 关键帧推拉 | `main` | 每个片段内 |
| 模糊背景填充（上下黑边消失） | `main` | 全部 4 个片段 |

**任意一项在剪映里看不到，请直接告诉我**——那就说明该字段在 11.4.2 上被忽略了，
我会改用别的表达方式，而不是让你手工补。

## 3. 导出设置

- **分辨率**：竖屏 1080x1920 / 横屏 1920x1080
- **帧率**：30fps（素材是 30fps；不要拉到 60，插帧只会糊）
- **码率**：导出后文件里若可选，1080p 取 **10–20 Mbps**
- **格式**：MP4 / H.264

### ⚠️ 关于「节奏」—— 这一条需要你先拍板

现在这版是 **4 个镜头 / 15 秒**（均值 3.75s，3 个切点）。
但两份独立证据都说它**偏慢**：

1. **本项目自己的素材分析**（`material-analysis.json`）：
   可用高光中位时长 **1.0s**、最长连续段仅 **3.4s**，结论原话是
   「可行的形式必须建立在**大量 0.5-1.5s 碎片** + 转场/字幕/音效缝合上」。
2. **本轮外部调研**（30 条可机检规则）：
   - 单镜头 **>3.5s 判失败**（>4s 硬失败）→ 本片的 c2=4.40s、c3=5.60s **两条硬失败**
   - 平均镜头时长目标 **1.0–2.0s** → 本片 **3.75s**
   - 每 15 秒切点数目标 **8–14** → 本片 **3 个（低于 [4,19] 下限）**

**冲突点**：项目自己的规则 `CUT-01`（固定四段结构、2:4:7:2）与 `CUT-02`
（切换密度 ≈12 切/分，即 [10,16]）**恰恰把慢节奏写成了硬规则**，
而且 `CUT-05` 要求每个高光前后留 ≥0.3s —— 在 0.5–1.5s 的碎片上**根本无法同时满足**。

所以「改节奏」= **改 P1 级规则**，我不擅自动。你选一个：

- **A. 保持现状**：规则不动，片子就是现在这样（已交付、已过 6 项门禁）。
- **B. 新增一版快剪**：不动现有规则，另出一版 `ep02` 快剪（约 8–12 个镜头、8–14 个切点），
  与现版**并存**供你对比。规则文档里加"另一种形式"的附注并标明它有意偏离 CUT-01/02/05。
- **C. 改规则**：把 CUT-01/CUT-02 改成兼容碎片化剪辑，并同步更新 6 个门禁脚本
  （工作量大，且会改动此前已验证的判定基线）。

**我建议 B**：它同时满足"出片优先"和"不动已验证基线"，而且你能直接拿两版对比。
