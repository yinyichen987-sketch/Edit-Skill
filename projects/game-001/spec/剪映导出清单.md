# 在剪映里导出成片 —— 人工操作清单

> 这份清单是给**人**看的。剪映 7+ **没有可自动化的导出接口**
> （`pyJianYingDraft` 的 `JianyingController.export_draft` 明确写着"仅支持剪映6及以下版本"），
> 所以最后一步必须由人在剪映里完成。
>
> 环境：剪映专业版 **11.4.2.14459**，草稿目录
> `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`

## 1. 只需要打开一次的自动化校准（30 秒）

`DSH_SIZE_LADDER` 里放了 4 个不同字号的同一句话。**你只要在剪映里点开它一次**，
剪映就会把 `draft_cover.jpg` 写到草稿目录；我随后用那张封面把「字号→像素」的换算钉死。

**为什么需要**：本轮已从剪映自渲染的封面实测出 `em_px ≈ 5.29 × size（**4 点标定实测**：8/14/20/26 四档反算均为 5.28–5.30，极差 0.02 线性成立；单点估计曾为 5.55，偏差 5%）`
（默认字号 8.0 → 实测 ink 高 43px、总宽 456px，两个独立量同时收敛到 em ≈ 44.4px）。
据此把字幕从 size 5.0/6.0 提到 17–24 —— **原值实际只有 ≈28–33px，小了约 3 倍**。

## 2. BGM：现在是本地合成的，建议你换掉

现在这条 BGM 是我**本地合成**的（`projects/game-001/bgm/bgm_128_15s.wav`，
128BPM / 8 小节 / 15.000s，实测底鼓在拍 / 拍间能量比 4.57、drop 在 7.5s 抬升 1.21×）。
理由：**剪映的曲库无法程序化引用**（`AudioSegment` 只收本地文件），
而自己合成能保证**拍点与剪切点严格同格**。

但它不是专业制作的曲子。**你充了会员，建议在剪映里换成热门曲**：

- 换曲后若想保持卡点：新曲 BPM 取 **120–140**（调研给出的电竞区间），
  并把 `projects/game-001/bgm/beat-grid.json` 里的拍点按新 BPM 重算。
- 现在的剪切点是 **0 / 0.9375 / 1.875 / 2.34375 / 2.8125 / 3.75 / 4.6875 / 6.5625 / 7.5 /
  8.4375 / 8.90625 / 9.375 / 11.25 / 12.1875 / 13.125 / 15.0 s** —— 全部是
  128BPM 的拍点（1 拍 = 0.46875s）。
- **最省事的做法**：在剪映里把音乐拖到 0 秒对齐，然后用"踩点"功能微调轨道位置。

## 3. 可选：把免费素材换成会员素材

**这一版所有素材都是免费的** —— 这是**故意的**，原因是一条硬约束：

> 剪映的滤镜/特效/字体都是**按 id 联网下载**的。本机 `Cache\effect\` 只缓存了 483 个 id；
> 调研抽查的候选 VIP 素材在**全部 29,724 个 User Data 文件里 0 命中**。
> 也就是说**没用过的 VIP 素材要在首次打开时下载，超时会显示"xx 加载失败"**。

"写进草稿"≠"打开就能用"。所以我用免费素材保证一次成功，把 VIP 作为**你可选的一键升级**：

| 想要的效果 | 免费（现用） | **会员升级**（在剪映里搜名字即可） |
|---|---|---|
| 电影感调色 | **青橙**（现用，强度 65） | 哈苏蓝 / 暗调电影 / 电影感增强 / 4K画质 / 徕卡银盐 |
| 故障感特效 | 冲击波 / 闪光震动 / 星火炸开（现用） | 像素故障 / 花屏故障 / 幻彩故障 / 色散故障 / 信号干扰 |
| 转场 | **闪白** 0.08s（现用） | 信号故障（已缓存，最稳）/ 故障扫描 / 像素冲屏 / 叠化扭曲 |

**注意**：换 VIP 素材后若显示"加载失败"，让剪映联网重下一次即可（不是草稿坏了）。

## 4. 人工必做的 3 件事

### 4.1 加限幅器（**EDL 表达不了**）

三段原素材的**真峰值都是 +0.8 dBFS（已经削顶）**。EDL 里只能写音量倍数，
写不出"限幅到 −1.0 dBTP"。请在剪映里：

1. 选中主轨视频 → 音频面板
2. 挂一个**限制器**，输出上限 **−1.0 dBTP**

> **两个实测坑**：
> ① `alimiter` 类插件的 **auto level 默认开启**，会把限幅结果再拉回去 ——
> 同一素材：默认时 **−10.5 LUFS / 真峰值 +0.6 dBFS（削顶）**；
> 关掉 auto level 后 **−13.4 LUFS / −1.7 dBFS（正常）**。**务必量真峰值确认。**
> ② 我这边预览成片的实测目标是 **−13.4 LUFS / 真峰值 −1.7 dBFS**，可作参照。

### 4.2 核对顶部遮挡与字框（竖屏专有）

- 规格只建模了抖音**底部 ≈300px** 与**右侧 ≈120px** 的 UI 遮挡带，
  **顶部遮挡没有建模**（`format-spec.md §13` 已声明）。
- 钩子"别眨眼"中心在 **300px**（字框 ≈[233, 367]）—— 请用**抖音预览**确认不被顶部压住。

### 4.3 特效与素材的"看得见"确认

剪映 11.x 对**不认识的字段是静默忽略**的（不报错、不显示）。请逐项确认：

| 该看到什么 | 在哪条轨 | 时间点 |
|---|---|---|
| 调色（青橙，全片一致） | main | 全部 15 个片段 |
| 模糊背景填充（上下无黑边） | main | 全部 15 个片段 |
| 冲击波 | `fx` | 0.00 / 4.6875 / 7.50 / 11.25s |
| 闪光震动 | `fx2` | 9.375s |
| 星火炸开 | `fx` | 13.125s |
| 闪白转场 0.08s | main | 1.875 / 4.6875 / 7.50 / 11.25s |
| 7 条字幕（含各自入场/循环动效） | `cap_top` / `cap_body` | 见下表 |
| BGM | `bgm` | 0–15s |
| 10 条音效（whoosh/riser/sub_drop/impact） | `sfx1` / `sfx2` | 1.875 / 5.625 / 7.50 / 8.4375 / 9.375 / 11.25 / 13.125s |
| 吸气镜（近乎静止的一拍） | main | 8.906–9.375s |

**任意一项在剪映里看不到，请直接告诉我** —— 说明该字段在 11.4.2 上被忽略了。

## 5. 导出设置

- **分辨率**：竖屏 1080x1920 / 横屏 1920x1080
- **帧率**：30fps（素材是 30fps；不要拉到 60，插帧只会糊）
- **码率**：1080p 取 **10–20 Mbps**
- **格式**：MP4 / H.264

## 6. 这一版仍然做不到的

| 限制 | 说明 |
|---|---|
| 剪映 7+ 无法自动导出 | 第 4 节必须人工 |
| EDL 表达不了限幅器 | 见 4.1 |
| 抖音顶部 UI 遮挡未建模 | 见 4.2 |
| 剪映曲库/音效库无法程序化引用 | BGM 与音效只能本地文件（合成或自备） |
| 没用过的 VIP 素材要联网下载 | 故本版全用免费素材，见第 3 节 |
| 蒙版在 11.4 上不可靠 | 本轮**刻意没用蒙版**（库自己的兼容矩阵标 ❌） |
| 曲线变速写不进去 | 只用了**线性变速**（吸气镜 0.5×）；曲线 `curve_speed` 库不支持 |
| 逐字卡拉OK做不到 | `content.styles[].range` 是**静态**的；逐字要靠**多段文本**拼，或用现成的"复古打字机"动效（本版用了后者） |
| 草稿打开后被剪映加密回存 | 工作区的 `projects/game-001/draft-out/` 是明文母本，**改片子要在那里改** |
