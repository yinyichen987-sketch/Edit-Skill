## 4. 人工必做的 3 件事

### 4.1 加限幅器（**EDL 表达不了**）

三段原素材的**真峰值都是 +0.8 dBFS（已经削顶）**。EDL 里只能写音量倍数，写不出"限幅到 −1.0 dBTP"。

1. 选中主轨视频 → 音频面板 → 挂一个**限制器**，输出上限 **−1.0 dBTP**

> **两个实测坑**：
> ① `alimiter` 类插件的 **auto level 默认开启**，会把限幅结果又拉回去 ——
> 同一素材：默认时 **−10.5 LUFS / 真峰值 +0.6 dBFS（削顶）**；关掉后 **−13.4 LUFS / −1.7 dBFS**。
> **"挂了限幅器"≠"限幅生效"，务必量真峰值确认。**
> ② 我这版预览实测 **−15.4 LUFS / 真峰值 −2.7 dBFS**（不削顶，但比抖音常见落点略保守）。
> 想要更响可以把主轨音量整体提 1–2 dB，再压限幅器。

### 4.2 核对顶部遮挡与字框（竖屏专有）

- 规格只建模了抖音**底部 ≈300px** 与**右侧 ≈120px** 的 UI 遮挡带，**顶部遮挡没有建模**。
- 钩子"别眨眼"中心在 **300px**（字框 ≈[233, 367]）—— 请用**抖音预览**确认不被顶部压住。

### 4.3 素材"看得见"确认

剪映 11.x 对**不认识的字段是静默忽略**的（不报错、不显示）。请逐项确认：

## v3 相对 v2 改了什么

1. **删除全部文字**（按你的要求"把所有的文字解说部分先删除"）——
   包括右上角那个计分板式 `2 KILLS`。片子现在只靠**画面 + BGM + 音效**说话。
   若你其实只想去掉"解说句"、保留数据条，说一声，我把 `2 KILLS` 单独加回来即可。

2. **变速改成阶梯式，不再一步跳完**（你反馈"击杀变速太生硬"）：

   | 位置 | v2（生硬） | **v3（阶梯）** |
   |---|---|---|
   | a 段（压 2 HP） | 0.70× → 1.15×（**一步差 0.45**） | 1.00× → **0.78×** → 1.10×（差 0.22 / 0.32） |
   | b 段（压击杀确认） | 1.15× → 0.70× | 0.95× → **0.78×**（差 0.17） |

   调研口径是"相邻倍数差 ≤0.5"，现在最大 **0.32**，留了余量。

3. 结构：**7 镜 / 6 切 / 30.000s**（3 个切点是场景切换、3 个是变速台阶）。
   全部切点仍落在 128BPM 拍点上；7 段在时间线上严丝合缝（逐段 Δ=0，无一微秒重叠）。

## ⚠️ 三个"我写不进去、但你一键就能开"的项

这三项都是剪映内核功能，`pyJianYingDraft` **没有任何可写字段**，所以只能你在剪映里开：

| 一键项 | 作用 | 为什么我写不了 |
|---|---|---|
| **① 曲线变速** | 把阶梯式变速变成**连续曲线**，彻底消除速度突变 | 库把 `curve_speed` **硬编码成 `None`**（源码 `segment.py:93`），无法写入 |
| **② 智能补帧 → 光流法** | 给慢放段补出中间帧，消除 30fps 慢动作的顿挫 | 库没有任何补帧/光流字段 |
| **③ 调节 → 对比度 +15 / 阴影 −10 / 色调 +5** | 教学文调色公式里属于**调节面板**的那三档 | 库从不写 `materials.adjusts` 等调节数组 |

**做法**：剪映里选中那几段变速片段 →「变速」→「曲线变速」；
「画面」→「智能补帧」选**光流法**；调色在「调节」面板补那三个值。
（颗粒 5% / 暗角 10% / 锐化 10% **已经写进草稿**了 —— 那三层是特效，能写。）
