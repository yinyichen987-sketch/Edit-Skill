## 4. 取段规则（可复算）

**击杀源**：`verification/icon-review/truth.json` 里 `verdict_mine == "Y"` 的事件，
**时刻取 `frame_true_note`**（= 徽记检测帧 + 人工在 `review.csv` 里填的 `kill_frame_offset`
**+ 从备注推出的偏移**。第 15 轮曾用过不含备注偏移的 `frame_true`，
导致 5 次击杀的时刻早 0.5s；本条片子的 3 条素材里没有那种行，
**所以本片的每一个时间码都没变**，见 `spec/击杀集锦_全素材_v1-统计与选片.md` §4）。

**取段**：用户原话「我们不做选择，我们做排除，把原始素材里是否有过长的无击杀的画面删除去除」（L4 项目策略）。

| 参数 | 值 | 含义 |
|---|---|---|
| `GAP` | 3.0s | 连续无击杀超过 3s 的区间 → 删 |
| `POST` | 1.5s | 删除区间左端留给**上一杀**收尾 |
| `PRE` | 0.6s | 删除区间右端留给**下一杀**前摇 |
| `MIN_CUT` | 1.5s | 真正能删的部分不足 1.5s ⇒ 这一刀不切 |
| `SNAP` | ±0.35s | 切点吸附到该窗口内**运动量最小**的一帧（`analysis2/motion.json` 逐帧帧间差） |
| 硬下限 | `POST_MIN` 1.0s / `PRE_MIN` 0.4s / `MIN_CLIP` 0.5s | 吸附后仍不许把击杀收尾/前摇切掉，也不出亚秒片段 |
| 落点 | 30fps 整数帧 + 整数微秒 | 时间轴用整数帧算、整数微秒累加，避免各自取整产生 1µs 重叠 |

> **这套参数已经被用户本人看过一次并判为可用**（2026-09-19，原话与适用范围见 §9）。
> 但**只验证过这 1 条短片**，还不能当成通用规则。

## 8. 本轮顺带得到的一个观察（L1，成因未验证）

徽记**外形在同一条素材内是一致的、跨素材不同**：
`7f0d8287` 是白色爪/角形，`b61cc53d` 是莲花（同一素材里还有蓝→红的变化），`9526869d` 是紫色尖刺。
⇒ 它更像是「**某一方**（大概率是玩家自己的英雄，或击杀特效皮肤）的图标」，
**不是**被击杀者的头像 —— 但本轮**没有**去验证成因（未查到权威说明）。
对后续标注的影响：**只要看到「画面中心出现圆形徽记」就可以当一次击杀候选**，不必先认形状。

> 形状匹配那条路（第 11 轮遗留的「提精度」）因此优先级更低：形状随英雄变，做模板匹配要先解决英雄分类。
