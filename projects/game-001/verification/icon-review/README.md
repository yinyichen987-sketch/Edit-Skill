# 人工标注：中心徽记 42 个高置信事件（第 11 轮）

**给谁看**：给**玩家本人**（或任何愿意逐张看图的人）。
**要产出什么**：`review.csv` 里每个事件的 `verdict_kill / verdict_mine / kill_frame_offset / note`。
**为什么值得做**：这是本项目**唯一还缺的关键输入** —— 没有它，所有判据都只有「对齐性」证据，
拿不到「准确率」。

## 1. 怎么看

1. 打开本目录里的证据图 `<素材>_p1.png`（11 张，每张 3–5 个事件，纵向排列）。
2. 每块图长这样（**块左上角有标题**）：

```
#序号  t=…s  frame=N  段长=Nf  peak=…  HC
┌────────────────────────┬────────────────────────┬────────────────────────┐
│ 整帧 f… (t−0.5s)       │ 整帧 f… (t)            │ 整帧 f… (t+0.5s)       │   ← 看当时在不在交火、有没有敌人
│   （红框 = 徽记位置）  │                        │                        │
├───┬───┬───┬───┬───┬───┬───┬───┐
│f−4│f−3│f−2│f−1│ f │f+1│f+2│f+3│                                            ← 徽记区逐帧：**徽记从哪一帧开始出现**
└───┴───┴───┴───┴───┴───┴───┴───┘
```

3. 把结论填进 `review.csv`（**用 Excel 打开**：文件带 UTF-8 BOM，中文不会乱码）。

> ⚠️ `review.csv` 的换行是 **LF**，不是 CRLF：本机 git 的 **system 级** `core.autocrlf=true`，
> 若文件是 CRLF，`git am` 会在收件方那边把它归一化成 LF ⇒ 交付包 tree 不一致
> （第 11 轮实测：1824 字节 CRLF=43 → am 后 1781 字节 CRLF=0）。**BOM 才是中文不乱码的关键**。

## 2. 每一列填什么

| 列 | 允许的值 | 含义 |
|---|---|---|
| `verdict_kill` | `Y` / `N` / `?` | 这一处**是不是一次击杀**（`N` = 徽记确实出现了但那次不是击杀，或徽记根本没出现） |
| `verdict_mine` | `Y` / `N` / `?` | 是不是**我**击杀（可看右上角播报里是不是「我」，或看敌人有没有倒下） |
| `kill_frame_offset` | 整数，例如 `-1` / `0` / `2` | **真实击杀帧 − `frame` 列**。看不出精确帧就留空 |
| `note` | 自由文本 | 例如「队友的击杀」「我被打死」「画面被特效盖住，看不清」 |

其余列（`material / event_id / t_s / frame / duration_frames / peak / high_conf / page`）
是工具写的，**不要改**。

### 已核对过的示范（`b61cc53d` 第 1 块）

证据图 `b61cc53d_p1.png` 第一块：第二行里 **f−2、f−1 还没有徽记，从 f−1 那格开始出现小徽记**
（实际目视的**首现帧是 f187**），而工具记的 `frame` 是 **188** ⇒ 该行应填：

    verdict_kill=Y   verdict_mine=Y   kill_frame_offset=-1

（第 4 格标的是 `f−1`，指 `frame-1 = 187`。）

- 42 = 11 条素材里**持续 ≥1s** 的「中心徽记」段（原始 91 段，亚秒段按场景噪点处理）；

## 4. 看的时候请留意这三件事（我们的遗留问题）

1. **助攻 / 自己阵亡时会不会也出徽记？** —— 这一条**没测过**，你在图里如果发现
   「徽记出现但不是我击杀」或「我死了也有徽记」，请填 `verdict_mine=N` 并在 `note` 里写清楚。
2. **徽记的首现帧是不是就是击杀帧？** —— 用 `kill_frame_offset` 告诉我们；
   如果普遍是 `-1`，说明工具的阈值慢了 1 帧（我们已经预期是 1 帧）。
3. **段长被全屏特效拉长的行**（`peak` 特别大的，例如 `b61cc53d` 第 1 行 `peak=0.809`）：
   那是击杀后紧跟的技能特效把框子照亮了，**首现帧仍然有效**，段长无效。
