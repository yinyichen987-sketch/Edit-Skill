### 基础校色顺序（教程画面上真正演示的）

`BV1KFKz6MEmL` 前 8 分钟是一条**单参数递进**的演示：老师把画面做成纯色块，一个一个加参数，
让你看清每个参数单独的效果，顺序可从口播与画面推进读出：

1. **黑/白色** 先切黑场白场（@20–35s：先把画面"变纯黑/变纯白"）
2. **色温 / 色调**（@33.5s 出现 `色温 -19` 的滑杆实例，见 `_frames/row_KFK.png` 左）
3. **饱和度 → 自然饱和度**（@140s 起：「整个画面就会变成黑白的」→ 只降绿不动肤色）
4. **亮度 → 对比度**（@232s「找到这个对比度」）
5. **高光 / 阴影**（@330s「然后就是调整整个画面的高光」）
6. **白色 / 黑色**（@360–440s「白色提高…是调整整个画面的」「看一下光感这个位置」）
7. **锐化 / 清晰** 收尾

> 教程**口播**对顺序的总结大意是「先黑白色定黑场白场，再色温色调定白平衡，再饱和度，再亮度对比，
> 然后 HSL / 曲线 / 色轮做二级」。上面 1–7 是**画面推进顺序**（L2，可复核），口播的概括属 L3。

| 时间段 | 平均 R/G/B | 平均饱和度 | luma p5–p95 跨度 |

**读数**：三档调色的**共同特征是把画面压暗到均值 ≈0.22、把平均饱和度压到 0.08–0.19**，

⚠️ 但它是**整段均值**，同一档内不同游戏镜头本身的颜色差异也被算进去了，**只能当方向，不能当目标值**。

## 坑与注意

1. **`BV1We411m7vg` 不是剪映教程**，是中文 After Effects。它的「三步」思路（局部发光 → …）可以看画面，
   但**任何面板名、参数名都不能当剪映口径引用**。判断依据是图层面板出现「调整图层/预合成」与插件面板「阈值/混合模式」。
2. **「蒙版」这个词在调色里指两件不同的事**：调节面板自己的第 5 个页签（对**这个调节层**生效），
   和画面/蒙版面板里的蒙版（对**片段**生效）。瓦教程用调节层 + 曲线，不要把两者混成一件事。
3. **色轮四盘的名字不确定，能看到两套叫法**：`暗部/亮部`（@745s）与 `阴影/高光`（@900s）。
   可能是不同版本、也可能是不同级色轮。**引用时用你本机看到的叫法。**
4. **别把瓦字幕里的数字当成"通用配方"**。它们是这位 UP 对**自己的素材**给的，且三档之间数量级差异很大
   （饱和度 3 / 15 / 17）。要当配方用，先在同一段素材上复现。
5. **字幕挡住参数名**：几乎所有剪映教程把口播字幕压在画面底部同一行，正好覆盖滑块左侧的参数文字。
   → 想读参数名，要**单独裁右栏**（`_frames/` 里以 `c_` 开头的都是这么来的），不要指望整屏截图。
6. **`BV16E3yzMEWW` 的调色数据是"字幕给的"，不是"面板读到的"**。这条按 L2 记（画面直接可见），
   但**没有一帧能同时看到数据表 + 该数据对应的滑杆位置**。若要更硬，需要在本机剪映按这些值复现一次比对。
