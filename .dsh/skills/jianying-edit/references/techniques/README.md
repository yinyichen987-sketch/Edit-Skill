# 手法库（techniques）—— 索引

这里是**「怎么做出某个效果」**的知识：剪映里的菜单路径、参数、前后顺序、时长量级、常见坑。
和另外两份文件的分工：

| 文件 | 管什么 | 能不能凭空写 |
|---|---|---|
| `editing-rules.md` | **风格**规则（你自己的片子怎么切、切多快） | ❌ 必须从**用户真实成片**归纳 |
| `operations.md` | **操作**事实（某功能叫什么、在哪、能否自动化） | ✅ 可验证，标来源即可 |
| **`techniques/`（这里）** | **手法**（做出某个效果的具体做法与参数） | ✅ 可验证，但**必须带来源与证据等级** |

## 证据等级（每个条目都要标）

| 级 | 含义 |
|---|---|
| **L1** | 本机**逐帧/逐像素实测**（从真实视频文件里量出来的数字） |
| **L2** | 从**教程视频抽帧直接读出的剪映 UI**（菜单路径、参数、预设名） |
| **L3** | 二手网页/往轮结论，**未被本轮复核** |
| **L4** | 本项目自己的既有决策（属于项目策略，不是通用手法） |

> ⚠️ **没有来源就写「未验证」，不要写数字。** 本项目已经抓到过一次：
> 某些流传的时长（「闪白 0.1 秒」「cut 后 3 帧」「变速 0.5 秒前开始」）**找不到任何来源**，
> 而它们看起来特别像"业内常识"。**看起来对 ≠ 有来源。**

## 两条必须一起读的元规则

1. **密度不是唯一真理，而且差异极大。**
   实测：`参考视频/` 里同品类两条成片分别是 **20.27 切/分** 与 **38.45 切/分**（响度差 14.5 LU）；
   而**用户自己的参考模板**是 **2.76–4.84 切/分**（11–31 秒长镜）。
   ⇒ 引用任何"节奏标准"之前，先问**参照系是谁**。

2. **剪映不是唯一实现路径。** 同一效果常有 2–3 条路（素材法 / 特效法 / 关键帧法）。
   本库记录**教程里实际演示的那条**，并尽量标出替代路径。
