# 蒙版（masks）

**定位**：剪映蒙版**有哪些形状、每个形状带哪些参数、各自用来干什么**，以及**蒙版怎么和关键帧配合动起来**。
每条标了证据等级与来源（见 `../README.md`）。

> **本轮证据构成**
> - **L2（剪映 UI 抽帧直读）来源 2 条**：桌面版 `BV1PuSKBLEcS`（「三分钟带你快速学会剪映蒙版的基本用法」，280s）、
>   手机版 `BV1sM4y1e7XL`（「手机剪映蒙版的5种玩法」，398s，480×852）。
> - **两个版本的 UI 差别很大**（形状数量一样，但参数项不同），下面**分开标注**，不要互相套用。
> - 桌面版那位 UP 的**摄像头人像压在右栏下方**，多次挡住「蒙版参数」下半部分——凡是被挡住的我都写进"未能验证"。
> - `projects/game-001/research/_scratch/pyJianYingDraft` 侧的上游枚举只支持 **6 种**（见 §本项目可生成的范围），
>   这属于 **L4 项目事实**，不是剪映的限制。

## 本项目可生成的范围（L4，项目事实不是通用手法）

`pyJianYingDraft`（本机 venv 实测）只提供 **6 个掩码枚举**：

```
MaskType = 线性, 镜面, 圆形, 矩形, 爱心, 星形
KeyframeProperty = position_x, position_y, scale_x, scale_y, uniform_scale,
                   rotation, alpha, brightness, contrast, saturation, volume
```

⇒ **`钢笔` / `钢笔画` / `文字` 这三个剪映真实存在的蒙版，EDL 路线生成不了**，必须写进交付说明交给人。
同理 `KeyframeProperty` 里**没有羽化、没有蒙版位置**——想用关键帧动蒙版，也让 EDL 表达，别假装做了。

## 坑与注意

1. **桌面版和手机版是两个不同的面板**。桌面有 9 个形状和"基础/形状"子页签；手机是横向滚动的形状条。
   **不要在手机教程里读到的参数去描述桌面版**（反之亦然）。
2. **`钢笔` 和 `钢笔画` 是两个不同的图标**，都在第一行/第二行。别把它们当成同一个。
3. **羽化只能在蒙版面板里调，不在"调节"里**。调色遇到的"羽化"属于蒙版，不是亮度参数。
4. **调节面板自己也有一页叫「蒙版」**（`color.md` §手法表）。那是**对调节层生效的蒙版**，
   和画面页签里的蒙版不是同一个入口，但形状逻辑一致。
5. **`+` 号意味着一个片段可以叠多个蒙版**。教程里星形那段明确演示了"添加多个蒙版""单独调整"。
   这对 EDL 是坏消息：现有 `mask` 字段按单蒙版设计。
6. **反转在不同版本位置不同**。手机版能直接读到 `反转` 文字；桌面版我没读到（可能被摄像头挡住）。
   引用时注明版本。
7. **别忽略摄像头遮挡这件事**。桌面这条教程的下半屏长期被人像覆盖，**任何"桌面版没有某参数"的结论都不可靠**。

## 未能验证（明确列出我没看出来的东西）

1. **矩形蒙版的「圆角」参数名与取值**。口播里出现过「比如说 35」这种数字、`_frames/mr_113_low.png` 里有一个 **44** 的滑杆值，
   但**标签全程被人像挡住**。所以「圆角」这个词我**没有在画面上读到**，值也不敢对应。
2. **圆形蒙版的专属参数**（比如宽高比、椭圆化）。我只有 `圆形` 这个图标名，**没读到它的参数行**。
3. **桌面版面板底部的「反转」**。手机版读到了，桌面版没读到——**不能因此说桌面版没有**。
4. **`钢笔画` 与 `钢笔` 的区别**。「钢笔画」我只有图标与名字（很像"钢笔+画笔"），**用途完全没看到演示**。
5. **`智能场景 / 智能橡皮 / 橡皮擦` 三个按钮的具体行为**。只读到按钮文字，没看到实际使用效果。
6. **文字蒙版的参数**。只看到图标和一句字幕，**没读到参数行**。
7. **蒙版配合关键帧的具体数值**（比如"第 0 秒位置 X=0，第 2 秒 X=500"）。关键帧那套数值是**在关键帧教程里用星星素材**演示的，
   **没有一条是蒙版的关键帧**。所以"蒙版动起来"我只能确认机制存在，**给不了配方**。
8. **羽化的取值范围**。只见到 0 / 65 两个点，**不知道上限是多少**（不要写 0–100）。
9. **蒙版的「基础 / 形状」两个子页签差别**。`基础` 下看到 9 个形状；`形状` 页签里有什么**没看到**。
