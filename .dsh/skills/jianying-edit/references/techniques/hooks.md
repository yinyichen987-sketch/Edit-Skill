# 开场与结局（hooks）

一条蒙太奇的**前 3 秒**决定别人划不划走，**最后 3 秒**决定他记不记得住。
本文件只记**教程里真的演示过的开场/结尾处理**，以及能实测出来的节拍位置。

> 证据等级见 `../README.md`。
> 本条目的 L2 来自两条**真的是瓦剪辑教程**的片子：`BV1ue8y6XE2M`（70s，超有氛围感的击杀结尾）
> 与 `BV1qx5463Exr`（67s，飞镖卡点）。
> `BV1o94y1a76h` 是 **AE** 教程，只取**设计意图**，其菜单与效果名一律标注 AE-only。

### 2.5 卡点教程自己讲出来的"卡点取帧法"（L2，逐帧读到的字）

这是本轮**唯一一条教程明确给出的、可直接执行的节拍取点规则**，原话：

> 「先导入捷风飞镖击杀素材」→「然后找到击杀片段」→「**找到爆头反馈亮起来的第一帧**」
> →「**再向后移动五帧**」→「将所有的片段都这样裁剪出来」

| 步骤 | 内容 | 等级 |
|---|---|---|
| 1 | 导入击杀素材 | **L2** `BV1qx5463Exr` @8s |
| 2 | 找到击杀片段 | **L2** @12s |
| 3 | **定位"爆头反馈亮起来的第一帧"** | **L2** @15s |
| 4 | **从这一帧再向后移动 5 帧**，作为裁切点 | **L2** @18s |
| 5 | 依此裁切所有片段 | **L2** @21s |
| 6 | 全选 → 给素材调到 **2 倍速** | **L2** @30s（片段上显示 `1.00x`→调后为 2 倍速，面板文字为「给素材调整成2倍速」） |
| 7 | 按音乐时长**多复制几份** | **L2** @33–36s |
| 8 | 先导出素材再预览，否则卡顿 | **L2** @39.7s「我们将这段素材导出」/ @42s「这样再预览就不会卡了」 |
| 9 | 时长还是不够就继续复制 | **L2** @45s |
| 10 | 最后全选素材 → **添加运动模糊** | **L2** @49–51s |
| 11 | 看效果 | **L2** @54s |

> ⚠️ 「**向后移动五帧**」是**帧数**，不是秒。它在 30fps 下等于 0.167s；
> **不要写成「0.17 秒」当规则**，教程说的就是帧。

## 3. 留白 / 停顿 —— 本轮到底找到了什么

**要求：如果教程演示了"留白/停顿"就明确写出来。结论是：只找到一处理由充分的，且它不是"全黑留白"。**

### 3.1 找到的（L1）：`BV1qx5463Exr` @37.0–41.5s 的"跳帧式静止"

按 0.2s 采样、看预览内容区（y180–700, x560–1360）的逐帧差异：

| 时间 | 预览区均值 lum | 与上一采样帧的差 | 读作 |
|---|---|---|---|
| 37.00 / 37.25 / 37.50 / 37.75 / 38.00 / 38.25 | 88.7（完全不动） | **0.0** | 画面**冻结约 1.3 秒** |
| 38.50 | 42.5 | 58.5（大跳） | 换镜/变暗 |
| 38.75 | 42.5 | 0.1 | 又冻住 |
| 39.00 | 44.5 | 25.5 | 变 |
| 39.25 / 39.50 | 44.5 | 0.0 | 冻住 |
| 39.75 | 217.6 | 173.1 | **一个很大的白块出现**（见下） |
| 40.25 | 76.0 | 49.6 | 变 |
| 40.75 / 41.00 | 209.5 | 136.3 | 再次大面积亮 |
| 41.25 | 88.7 | 132.2 | 回落 |

**解释（重要）**：@39.75s 那一下的"大面积亮"**不是画面留白**——
逐帧看过，它是**教程作者直接糊在预览区上的一块白色方框**（用于遮挡/示意），
同一帧底部字条写的是「我们将这段素材导出」。
所以这一段**不能当成"剪映里做了闪白/留白"的证据**。

**能成立的那一条**：@37.0–38.25s 预览区**逐帧差异为 0.0、持续约 1.3 秒**，
是一个**真实的画面静止**（教程当时停在某个结果上讲解）。这是"停顿"行为，但**不是音乐留白设计**。

### 3.2 没找到的

- **没有在任何一条瓦剪辑教程里看到"故意放一段全黑/全白来留白"的演示。**
- 因此**"结尾前留白 0.5 秒"之类的话本轮没有来源，不许写。**

### 3.3 最接近"留白"的真实现象（L1，`BV1ue8y6XE2M`）

`BV1ue8y6XE2M` @30.4s 起，预览区有**约 4 秒的近全黑**（均值 lum **5.4**）。
但看画面可知，那 4 秒里剪映正停在**效果参数面板**上让观众看参数，**属于讲解停顿，不是成片设计**。
→ **两处"停顿"都不是设计手法**，所以本文件把它归为"留白未被证实"。

## 4. 坑与注意

1. **"教程里的演示片"和"教程本身"是两条时间线。** 同一个 mp4 里，
   剪映的工程时长、教程旁白时间、你看到的实际时间**三者都不同**。
   引用任何时间点，必须写清是**教程视频的时间**（本文件全部是教程视频时间）。
2. **卡点看的是"爆头反馈亮起来的第一帧"，不是击杀播报。**
   与 `kill-moment.md` §2 的结论同向：**别对齐播报横幅**。这次是教程原话（L2），比那边继承来的 L3 硬。
3. **`BV1qx5463Exr` 的开场预览卡是"成品展示"，不是"可照抄的剪映操作"。**
   相框、霓虹描边、标题卡的制作过程**教程里没演**（§5），只量到了几何。
4. **结尾那 7.3 秒不是硬定格。** 三帧 MD5 不同，说明还有极缓慢变化；
   写 EDL 时别设成完全静止的 freeze（除非你自己要那个效果）。
5. **AE 的设计意图不能当剪映菜单抄。** `BV1o94y1a76h` 里的
   调整图层（Ctrl+Alt+y）、`Twixtor Pro`、`WarpChroma`、`Twitch`、`Analog` 都是 **AE-only**，见 §5。
6. **切点密度差异极大**（本文件量到 32.7 切/分，而本项目参考模板是 2.76–4.84 切/分）。
   引用前先读 `../README.md` 的元规则 1：**先问参照系是谁**。
