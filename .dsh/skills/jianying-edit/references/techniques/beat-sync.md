# 卡点 / 踩点（beat-sync）

**定位**：把"素材怎么对上音乐"这件事写清楚 —— 节拍怎么标出来、什么落在拍上（切 / 闪 / 特效 / 字幕）、
以及一套**中文教程里确实存在的"抽帧卡点"**做法。
每条都标证据等级（见 `README.md`）：**L1** = 本机实测；**L2** = 从教程抽帧读出的剪映 UI；**L4** = 本项目策略。

> 本批 5 条教程里，**卡点讲得最实的是 `BV1EahSzYEc8`（抽帧卡点，50 s）和 `BV1zz4y1N7Dp`（卡点+转场，157 s）**，
> 两条都完整展示了剪映的踩点面板。`BV1fEbK6xEaP`（瓦，110 s）**没有任何剪映界面**，
> 它只能作为"卡点成片长什么样"的 L1 样本。

## 3. 坑与注意

1. **"抽帧卡点"在这条教程里 ≠ 手动删帧。** 教程从头到尾**没有出现"删帧/抽掉几帧"的操作**，
   它实现"抽帧感"的手段是 **曲线变速把速度压到 0.6x / 0.3x**（+ 智能补帧），
   让每段的**时长刚好对上一个拍点**。
   ⇒ 谁要复刻"抽帧卡点"，找的应该是 `变速 → 曲线变速 → 改速度值`，不是逐帧删除。
   ⚠️ 但这条**教程本身没有解释"抽帧"两个字指什么**（见 §4 第 1 条）。

2. **两条教程的踩点操作是"手工对位"，不是"自动吸附"。**
   `BV1zz4y1N7Dp` 里 UP主反复说"把这个卡点对齐"、"以此类推"，
   画面里是他**把播放头拖到黄点上、再拖素材**。我**没有看到任何"吸附/自动对齐素材到节拍"的开关**。
   ⇒ 不要写成"剪映能自动把片段吸附到节拍"。

3. **自动踩点在两条视频里都被用作"先标拍、再干活"。**
   `BV1EahSzYEc8` 的流程是：导入 BGM → 点节拍 → 自动踩点 → **然后才开始选视频、调变速**。
   `BV1zz4y1N7Dp` 里 UP主是在讲素材拖进来之前就先把踩点标记打好了。

4. **不要把 `闪进` 当成"抽帧卡点"的必选项。** 画面证据只能说：
   `BV1EahSzYEc8` 的曲线变速面板里，**预设名读数为「闪进」**，曲线被拉成匀速 0.6x/0.3x；
   同时字幕出现过"加一个**闪进**变速"和"添加一个**闪出**变速"两种说法。
   这两件事谁是"预设名"、谁是"UP主口播的俗称"，我**没能分清**（见 §4）。

5. **节拍密度不要从这两条教程反推。** 两条都没报 BPM，也没报"一拍多少秒"。
   我在抽帧上看到的黄点间距是**跟着具体那首 BGM 来的**，与"瓦片该用多快"无关。

6. **`BV1M9KB6GEQA` 里"逐帧重复"的数字不能用来算卡点密度。**
   实测它 21.33 fps，却有 **67 段**"相邻帧完全相同"（如 t=15.19s / 15.47s / 15.85s…），
   大量出现在 **t≈15–17s**（正是打开踩点面板的时候）、**t≈32–40s**（正在拖参数）。
   ⇒ 那是**录制工具在 UI 静止时丢帧/重复帧**，不是剪辑师的定格。同理 `BV1zz4y1N7Dp` 的 579 段重复帧也是录屏假象。

7. **`BV1fEbK6xEaP` 的过曝白闪不能当成"白闪卡点"来引用。**
   它片中 t=13.30s 还有一帧亮度 134.4、>200 灰阶像素占 7% —— 那只是瓦尔特的**亮天空**，
   被"亮度超过基线 1.5 倍"的检测器误判。我核对过：真闪只有 t=59.333s 那次。

## 4. 未能验证

1. **"抽帧"到底指什么。** 教程的**标题和开篇字幕**叫它"抽帧卡点"，
   但**全片没有出现任何"删帧 / 抽掉几帧 / 保留几帧"的面板或操作**，
   只有 `变速 → 曲线变速 → 0.6x/0.3x`。我没有看到 UP主解释这两个字。
   ⇒ **"抽帧 = 每 N 帧丢 1 帧"这个理解在本批素材里找不到来源。**
2. **抽帧"每拍几段 / 每段几帧"的具体配方。** 教程只在时间轴上摆片段，
   **没有口头给出任何"一段几帧"的数字**。我不写。
3. **曲线变速里那些控制点被拖到哪个精确位置。** 我只能读到"数值框 0.6x / 0.3x"，
   **读不出曲线上每个点的坐标**（1x/0.1x 只是纵轴刻度）。
4. **`闪进`（曲线预设名）与字幕里的"闪进变速"/"闪出变速"是否指同一件事。** 未确认。
5. **"智能补帧"开与关对这个手法的实际影响。** 教程把它点亮了，但**没有对比**。
6. **`BV1fEbK6xEaP` 的切点是不是真的落在 BGM 的拍上。** 
   它**没有剪映界面**，我无法看到拍点标记；要验证只能自己抽 BGM 做 L1 节拍检测，
   **本轮没做**。所以它的黑场/白闪**是不是"卡点"行为，属于未验证**。
7. **`BV1zz4y1N7Dp` 里 UP主最终选中的那个转场名**（在 模糊 分类里，时长 0.5s）—— 读不出来，未验证。详见 `transitions.md`。
8. **两条教程各自的 BPM / 节拍间隔。** 画面里没有 BPM 显示，我也没做音频 L1 分析。
9. **瓦片里"音乐结构 → 剪辑结构"的对应关系。** 
   本批 5 条教程**没有一条**讲"前奏怎么排、drop 怎么排、副歌怎么排"。
   `BV1fEbK6xEaP` 只能看到"结尾有一段长达 10 s 以上的黑场收尾"（L1，t=99.333s 起到片尾），
   除此之外的段落划分依据**未验证**。
