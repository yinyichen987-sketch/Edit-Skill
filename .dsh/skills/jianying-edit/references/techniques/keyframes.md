# 关键帧（keyframes）

**定位**：剪映里**哪些属性可以打关键帧、两个关键帧怎么成对设置、有没有缓动、以及位移/缩放/旋转的实例**。
每条标了证据等级与来源（见 `../README.md`）。

>   `BV1KFKz6MEmL`（36 分钟调色课，**桌面版剪映**）——提供**桌面版的打帧入口**。

>   桌面版是另一套（见 §桌面版差异）。**不要混用。**
> - 教程自己的目录卡（@~28s，`_frames/z_KF_b.png`）列了它要讲的 5 件事：

## 坑与注意

1. **"改参数自动打帧"是剪映的真实行为，必须知道**。字幕原话「当属性发生变化的时候，系统自动给我们打上了关键帧」
   —— 落到本项目就是：**给已有关键帧的片段再改参数，会自己生成新帧**，生成草稿时要小心别打出多余的帧。
2. **一个菱形 ≠ 一个属性**。同一时刻位置和缩放都变时，**只有一个菱形**（"一个关键帧可以同时记录多个属性信息"）。
   做 EDL 时不要把 `position_x` 与 `scale_x` 的帧当成两个独立对象去对时间轴。
3. **手机版和桌面版面板名不一样**。手机版是 `位置/缩放/旋转` 三个页签；桌面版是"每个参数行尾部一组菱形按钮"。
   引用时带版本。
4. **教程标题写着"86"**（`【剪映教程】86-深度讲解关键帧`），说明这是某个系列的第 86 集。
   **不要**据此推断其它集的内容。
5. **这条教程全程用一颗星星贴纸演示**，**没有一帧是游戏素材**。所以它证明的是**机制**，
   **不能直接当"瓦剪辑的击杀慢放要打几个关键帧"的配方**。
6. **桌面版本课（`BV1KFKz6MEmL`）没有演示时间轴上的关键帧图形**。别把手机版的"素材条内白色菱形"说成桌面版的样子。
7. **`KeyframeProperty` 里没有的东西不要去写**（没有羽化、没有蒙版位置、没有"不透明度"这个中文字面）。
   透明度的上游枚举名是 **`alpha`**（L4，本机实测），不是 UI 上的中文。
