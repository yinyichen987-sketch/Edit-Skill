## 规则优先级

规则冲突时的取舍顺序。数字越小优先级越高。

| 级别 | 类别 | 说明 |
|---|---|---|
| P0 | 安全 / 硬约束 | 不输出缺素材、黑帧、爆音、错误比例 |
| P1 | 叙事意图 | 先保证故事逻辑，再追求节奏 |
| P2 | 结构规则 | 每段必须有明确的信息单位 |
| P3 | 节奏规则 | 在信息完成处切，不按固定秒数机械切镜 |
| P4 | 视音频风格 | 默认硬切；转场须满足条件 |
| P5 | 可选打磨 | 有余力再做细节动画与装饰 |
