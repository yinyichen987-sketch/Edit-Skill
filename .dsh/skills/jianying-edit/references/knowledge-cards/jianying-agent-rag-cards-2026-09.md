# JY-CORE-001｜精确分割

**分类：** 时间线基础  
**置信度：** high  

## 1. 编辑意图

在播放头位置把一个片段切成两个独立片段

## 2. 什么时候使用

需要删除、单独变速、单独加效果、单独处理素材中间一段

## 3. 剪映执行步骤

1. 定位播放头到目标切点
2. 执行 Ctrl+B（Mac 为 Command+B）
3. 确认切点两侧已经成为独立片段

## 4. 为什么使用

先建立精确切点，再做局部操作，比直接大范围删除更安全。

## 5. 约束与禁忌

- 快捷键可能被自定义；执行前以当前快捷键设置为准

## 6. 完成后验证

- 时间线上出现两个相邻独立片段

## 7. RAG 检索关键词

分割, 切开, Ctrl+B

# JY-CORE-002｜删除片段

**分类：** 时间线基础  
**置信度：** high  

## 1. 编辑意图

删除已经明确判断为无效的片段

## 2. 什么时候使用

口误、空白、重复、错误镜头已经被准确界定

## 3. 剪映执行步骤

1. 选中目标片段
2. 执行 Delete/Backspace
3. 检查时间线是否按预期闭合或保留间隙

## 4. 为什么使用

删除是破坏性操作，所以应建立在“目标范围已明确”的前提上。

## 5. 约束与禁忌

- 不要把“可能不需要”直接等同于“删除”
- 多轨情况下注意是否联动

## 6. 完成后验证

- 目标片段从时间线消失
- 上下游素材关系符合预期

# JY-CORE-009｜联动编辑

**分类：** 时间线基础  
**置信度：** high  

## 1. 编辑意图

让其他轨道素材跟随主轨素材同步移动或删除

## 2. 什么时候使用

视频、字幕、音频、B-roll存在同步依赖

## 3. 剪映执行步骤

1. 识别需要同步的相关轨道
2. 启用合适的联动关系
3. 移动或删除主轨片段

## 6. 完成后验证

- 关键同步素材未漂移
